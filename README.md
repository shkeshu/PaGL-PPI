# PaGL-PPI: compact code and data release

This repository contains the PaGL-PPI model implementation, the five fixed pair/label datasets, configuration files, the code that computes manuscript Tables 3–7 from model result summaries, and five small reference tables. The `Data/` directory has exactly the five CSVs requested for upload plus its README.

## Layout

```text
Data/
  README.md
  bernett/train_pairs.csv
  bernett/validation_pairs.csv
  bernett/test_pairs.csv
  external/human_test.csv
  external/yeast_test.csv
Configs/
Scripts/00_...py to 16_...py
Results/paper_results_final_v2/tables/table03_...csv to table07_...csv
requirements.txt
```

See `Data/README.md` for the three public FASTA sources needed to turn protein IDs into ESM2 features. See `REPRODUCE.md` for the ordered model and table workflow.

The repository does not include pretrained ESM2 weights, generated embeddings, checkpoints, per-pair predictions, exploratory t-SNE/case-study code, or old diagnostic results. These are regenerated by the scripts or supplied by their original sources. A full reproduction therefore requires the three source FASTAs, GPU resources, model training, and external ESM2 feature generation. The included five result tables let readers inspect the reported numbers immediately; `Scripts/16_finalize_paper_results.py` can regenerate them after the model runs. The paper's Figure 4 t-SNE analysis and Figures 5/8–10 attention case studies are outside this compact release.
